Les principes de ce diagnostic
  • Le cœur de métier est au centre : le pilotage s’élève, le support s’allège, le cœur se sublime.
  • Les feux sont déclaratifs aujourd’hui ; ils seront mesurés par l’usage demain.
  • Aucun score sur les personnes : la maturité de l’organisation s’exprime en paliers.
  • Les 60 questions portent sur le dispositif de l’entreprise, jamais sur le ressenti individuel.
  • Une seule finalité : libérer du temps pour le geste humain rare.
